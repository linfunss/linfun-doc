# Simple Voice Chat 模组使用方法

模组地址：[[SVC]简单的语音聊天 (Simple Voice Chat)](https://www.mcmod.cn/class/3693.html)

相比起单开一个聊天软件，显然是能够内置在mc内的更加方便和通用。不过就是服务器端的配置步骤就要多一些。

---

### 服务器的设置~

此教程基于**内网穿透版本**，如果你的服务器有公网地址（那是当然的，但是我没有😭）就暂时跳过

1. 在服务器主目录的 config/voicechat 中有一个 voicechat-server.properties 文件。该文件中有两个部分需要注意：

   ```properties
   # 服务器监听端口
   port=24454

   # 客户端访问地址
   voice_host=
   ```

   第二个地址需要填写利用内网穿透**监听端口**后的映射地址，客户端的配置文件无需做任何修改。

   > 如果你是联机而非开服务器，那么客户端配置文件中也有对应文件，内容需要修改

2. 那么你就需要配置两条隧道进行穿透（端口为默认情况，你可以酌情修改）

   | 名称    | 协议      | 本地端口  | 映射地址                  |
   | ----- | ------- | ----- | --------------------- |
   | MC服务器 | TCP     | 25565 | frp-example.com:12345 |
   | 语音模组  | **UDP** | 24454 | frp-example.com:23456 |

然后你就只需要吧服务器的地址发给好友就可以了，模组会自动处理连接并且进入新手教程
