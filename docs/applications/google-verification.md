# Google 手机验证记录

我的谷歌小号在登陆反重力的时候遇到了账号需要验证的情况，如果点进去验证链接，是个二维码。

<u>如果直接用手机浏览器扫码，会给你跳转到浏览器网页，要你手动发验证码给谷歌。但是很显然国内是发不过去的，导致验证卡住了。</u>

经过几天的摸索，方法是：

1. 首先确保你谷歌账号的各个验证措施完整，没有也给他补完

   ![Google 账号登录选项：两步验证、通行密钥、身份验证器和恢复方式，个人信息已遮挡](/images/google-sign-in-options.png)

   在我当时的流程中，辅助电话号码可填写 +86 手机号；是否需要短信、是否接受该号码，由 Google 当前验证流程决定。

2. 可以打开 [谷歌云shell](https://shell.cloud.google.com/) 这个登陆谷歌账号的时候如果你的账号是需要验证（即登陆反重力遇到了验证的）。你就可以在这里进行验证，此时就弹出来验证二维码

3. 接下来是：在手机中，不要使用浏览器扫码，尽量使用系统自带的软件扫码，例如：我使用的小米手机有 `AI扫描` 这个看起来很不正经。

   在扫描后，他会跳转到系统的google play 套件中， 当时点击下一步后完成了设备验证，没有再手动发送短信。这只是一次经历，不保证适用于其他账号或后续流程。
