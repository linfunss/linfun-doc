# GSAP 属性速查

| 属性         | 描述                                       | 默认         |
|:---------- | ---------------------------------------- | ---------- |
| duration   | 动画变化的时长                                  | 0.5（s）     |
| delay      | 动画开始的延时                                  | 0          |
| repeat     | 重复次数                                     |            |
| yoyo       | true：动画执行完后会反向执行一次                       | false      |
| stagger    | 元素间隔时长。多个元素的动画按指定间隔依次开始 |            |
| ease       | 动画曲线设置                                   | power1.out |
| onComplete | 执行结束的回调函数                                |            |

---

## 位置参数属性

用来确定在timeline模式下，动画触发的时机

timeline解释：顾名思义，会让旗下所有的动画依次执行（默认情况）

> gsap.to(".boxs", {}, "在这里")

| 值类型      | 说明                               |
| -------- | -------------------------------- |
| 1        | 绝对时间，固定将在时间线开始 1s 后执行            |
| 0        | 固定在时间线起点执行          |
| `<`        | 与上一个动画起点对齐：会与上一个动画一起开始           |
| `<1` / `<-1` | 间隔 1s / 提前1s                     |
| `>`        | 与上一个动画结束对齐：会在上一个动画结束后执行（默认追加到时间线末尾时可相同） |
| +=1      | 在时间线末尾 1s 后开始                   |
| -=0.5    | 在时间线末尾前 0.5s 开始                   |

```javascript
/*
    gsap 的方法有四种：
    1. gsap.to()   让元素从初始状态变化到目标状态
        例如：让盒子主动向一个地方移动。盒子从初始的位置移动。

    2. gsap.from()   让元素从目标状态变化到初始状态
        例如：进场动画，从一个位置进入到预定位置

    3. gsap.fromTo()  定义两个状态的数据，然后从开始变到结束
    4. gsap.set() 设置成想要的任何状态，没有过渡与动画效果,即duration为0
  */

  /** gsap使用的是css选择器来查找元素，赋予动画效果
   *  ".boxs" 或者更复杂的 选择器，例如：".boxs .item"
   *
   *  在vue中可使用响应式模板绑定 const xxx = ref(null)
   * 在标签中 <div ref="xxx"></div>绑定
   */

  /** gsap还有一个参数是变化的数据对象
   *
   * 这个对象包含变化动画的相关属性，例如坐标位置变化
   * 变换时间，触发事件等
   * 常用属性：
   * x,y  坐标轴（px）
   * xPercent yPercent 坐标轴百分比（%）
   * scale  缩放
   * transformOrigin  变换原点
   * rotate  旋转
   * skewX,skewY  Y轴或者x轴旋转变换
   *
   * skewX,skewY  X轴或者Y轴的倾斜
   *
   * opacity  透明度
   * duration  持续时间
   * ease  动画效果
   *
   * 还可以接管css中的所有变换效果。
   */

  /** 时间线，可以方便管理多个动画
   * 会默认按照动画结束时自动播放下一个动画
   *
   * 也可以通过设置delay延时来让当前动画延时设置
   *
   * 位置参数：可以用来固定某个动画开始的时机，比如让两个动画
   *  同时开始。默认属性跟在动画属性后面   gsap.to(".boxs", {}, "在这里")
   *
   * 可以设置时间线defaults参数，来简洁代码
   *
   */
```
